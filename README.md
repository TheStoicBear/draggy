# 🏁 Draggy

*A comprehensive benchmark system for testing vehicles in a drag race environment.*

![Logo](https://imgimp.xyz/images/Stoic-2025-04-14_17-58-45-67fd4cd5579d0.png)

---

## 🚀 Features

- ✅ Real-time speed and performance tracking *(MPH, HP, Torque)*
- ✅ Track benchmarks:  
  - Speed: 0-60, 0-100  
  - Distance: 1/8 mile, 1/4 mile, 1/2 mile, 1 mile  
- ✅ Displays vehicle class, name, and power stats
- ✅ In-depth stats with an intuitive UI
- ✅ Easy-to-implement client-side commands for seamless integration into your server

---

## 🔍 Features Overview

- 🚗 **Accurate performance metrics** for speed and distance  
- ⚡ **Power stats**, including average and max horsepower and torque  
- 🏁 **Race control** with start/stop/reposition commands via UI  
- 📊 **Benchmark logging** to compare results with others  
- 🖥️ **Fully responsive UI** with customizable settings

---

## 🎯 Perfect For

Draggy is designed for **FiveM racing servers** looking to enhance the player experience with:

- Competitive, performance-focused drag races  
- Precision vehicle testing and tuning  
- Customizable telemetry and visual stats  

> Whether you're hosting high-speed races or testing vehicles for top performance — **Draggy has you covered!**

## 🛠️ Installation

1. Download the `.zip` file from the link above  
2. Extract it into your FiveM resource directory  
3. Add `ensure draggy` to your `server.cfg`  
4. Use `/draggy` in-game
